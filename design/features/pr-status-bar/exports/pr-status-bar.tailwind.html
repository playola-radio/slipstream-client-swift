B · Chat: the message is short, the instructions ride along as a chip
The button writes the instructions to ~/Library/Application Support/Slipstream/attachments/<id>/<name>.md (outside the worktree, so it never shows as a change) and sends the agent one line ending in an @⟦name⟧(path) marker. The chat draws the marker as a chip; clicking it opens the file. The chip survives reopening the chat because the marker is part of the message text. Commit and push and Resolve conflicts have no file, so they're plain messages.
